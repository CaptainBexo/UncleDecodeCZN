# CZN MM/MI auto-update (v0.5) - Implementation Plan

> **For Hermes:** planning only; implement task-by-task with `test-driven-development`
> where it applies. The project's test harness is `ui/qa_check.py` (run it after every
> task), not pytest.

**Goal:** the app knows when a newer version is published and points the user at it -
a "Check update" button in **Settings**, plus one silent startup check in the frozen exe.

**Architecture:** one new stdlib-only module `ui/updater.py` (fetch + version compare +
QThread wrapper), a new row on the Settings page, a one-shot startup check. v1 = *detect
and link* (open the download page) - **no self-replacing binary in this phase**; the
self-replace shim is deliberately left to a later opt-in phase (see "Phase 2" at the end).

**Tech stack:** PySide6 (QThread/Signals, QDesktopServices, QMessageBox), stdlib
`urllib.request` + `json` + `re`. No new dependencies.

## Decision needed before Task 1 (blocking, user)

Where the update metadata + the zip live. The repo is **private**, so the app cannot
read GitHub releases without shipping a token (never do that).

| Option | Extra work | Notes |
|---|---|---|
| **A. Make `CaptainBexo/UncleDecodeCZN` public** *(recommended)* | none - releases already exist | The app hits `https://api.github.com/repos/CaptainBexo/UncleDecodeCZN/releases/latest` unauthenticated (60 req/h/IP). The repo history is already scrubbed of personal data, the tool is free - this makes the release page itself the download page. |
| **B. Keep the repo private; host a static `latest.json` + the zip on Cloudflare R2** | release script gains an upload step; a bucket | Free tier (10 GB storage, zero egress). The check and the download are fully under your control; nothing of the repo is exposed. |

`ui/updater.py` keeps ONE constant `UPDATER_URL` and a 6-line normalizer that accepts
**both** payload shapes, so this decision changes exactly one line. Default in the code
below = option A (no extra infra); appendix has the R2 upload snippet for option B.

**Payload shapes the normalizer handles**

- GitHub: `GET https://api.github.com/repos/<repo>/releases/latest` ->
  `{"tag_name": "v0.5", "body": "...", "html_url": "...", "assets": [{"browser_download_url": ..., "digest": "sha256:..."}]}`
- Static `latest.json` (option B):
  `{"version": "0.5", "url": "https://.../UncleCZNMMMI-v0.5.zip", "notes": "...", "sha256": "..."}`

Normalized result: `{"version": "0.5", "url": <zip>, "page": <release page>, "notes": <markdown>, "sha256": <hex|None>}`.

```python
"""Lightweight update check: fetch the latest release metadata, compare with the
running version. stdlib only - no extra dependencies, no telemetry, one plain GET.

Host choice lives in UPDATER_URL (see the plan): the GitHub releases API of a
public repo, or a static latest.json ({"version","url","notes","sha256"})."""
from __future__ import annotations

import json
import re
import urllib.request

from PySide6.QtCore import QThread, Signal

import version

UPDATER_URL = "https://api.github.com/repos/CaptainBexo/UncleDecodeCZN/releases/latest"
TIMEOUT_S = 6


def _parts(v: str) -> tuple:
    return tuple(int(p) for p in re.findall(r"\d+", str(v))[:3]) or (0,)


def newer(current: str, latest: str) -> bool:
    """True when `latest` is a strictly newer version than `current`."""
    a, b = _parts(latest), _parts(current)
    n = max(len(a), len(b))
    return a + (0,) * (n - len(a)) > b + (0,) * (n - len(b))


def parse(payload: dict) -> dict:
    """Normalize both payload shapes; KeyError/ValueError = unusable response."""
    if "tag_name" in payload:                       # GitHub releases/latest
        assets = payload.get("assets") or []
        zips = [a for a in assets if str(a.get("browser_download_url", "")).endswith(".zip")]
        if not zips:
            raise ValueError("no zip asset in the release")
        a = zips[0]
        return {"version": str(payload["tag_name"]).lstrip("vV"),
                "url": a["browser_download_url"],
                "page": payload.get("html_url", ""),
                "notes": payload.get("body", ""),
                "sha256": str(a.get("digest", "")).removeprefix("sha256:") or None}
    return {"version": str(payload["version"]),
            "url": payload.get("url", ""),
            "page": payload.get("url", ""),
            "notes": payload.get("notes", ""),
            "sha256": payload.get("sha256")}


def fetch(url: str = UPDATER_URL) -> dict:
    """GET + parse; raises on any failure (the caller decides how quiet to be)."""
    req = urllib.request.Request(url, headers={"User-Agent": "czn-updater",
                                               "Accept": "application/vnd.github+json"})
    with urllib.request.urlopen(req, timeout=TIMEOUT_S) as r:
        return parse(json.loads(r.read().decode("utf-8")))


class UpdateCheck(QThread):
    """Runs fetch() off the UI thread; result = normalized dict or None (+ why)."""
    done = Signal(object, str)              # (result|None, error text)

    def run(self) -> None:
        try:
            self.done.emit(fetch(), "")
        except Exception as e:              # noqa: BLE001 - offline/timeout/bad json
            self.done.emit(None, "%s" % e)
```

```python
    # imports: + from PySide6.QtGui import QDesktopServices   (QUrl already imported)
    #          + import updater, version

    def _check_update(self) -> None:
        """Manual check from Settings: one GET, then report in the row/dialog."""
        if getattr(self, "_upd_thread", None) is not None:
            return                                  # already checking
        self._upd_btn.setEnabled(False)
        self._upd_lbl.setText("Checking...")
        self._upd_lbl.setVisible(True)
        self._upd_thread = updater.UpdateCheck(self)
        self._upd_thread.done.connect(self._update_checked)
        self._upd_thread.finished.connect(self._upd_thread.deleteLater)
        self._upd_thread.start()

    def _update_checked(self, info, err) -> None:
        self._upd_thread = None
        self._upd_btn.setEnabled(True)
        if info is None:
            self._upd_lbl.setText("Check failed (offline?)")
            return
        if not updater.newer(version.VERSION, info["version"]):
            self._upd_lbl.setText("You're on the latest version")
            return
        self._upd_lbl.setText("Update available: v" + info["version"])
        box = QMessageBox(self)
        box.setWindowTitle("Update available")
        box.setText("Uncle'sCZNMMMI v%s is available (you have v%s)."
                    % (info["version"], version.VERSION))
        if info.get("notes"):
            box.setDetailedText(info["notes"])
        open_btn = box.addButton("Open download page", QMessageBox.ButtonRole.AcceptRole)
        box.addButton("Later", QMessageBox.ButtonRole.RejectRole)
        box.exec()
        if box.clickedButton() is open_btn:
            QDesktopServices.openUrl(QUrl(info["url"] or info["page"]))
```

**Files:** none (process only)

1. QA: `cd ui && QT_SCALE_FACTOR=1 ../.venv/Scripts/python.exe qa_check.py 2>&1 | tail -1` -> `all checks passed`
2. Build: `.venv/Scripts/python.exe scripts/build_exe.py` - the privacy audit runs inside;
   must print `== clean ==` and assemble `release/Uncle'sCZNMMMI v0.5/` + `.zip`.
3. Smoke: run `scratch/czn_release_smoke.py` (update the exe name to v0.5) - window shows, clean exit.
4. Manual live check (after the host decision): run the exe, Settings -> Check update;
   verify against the real endpoint. With **no** newer release it must say "You're on the
   latest version" - that is the honest v0.5 test until v0.6 exists (then it must say
   "Update available: v0.6" and the dialog must open the release page).
5. Release: create the GitHub release `v0.5` with `README_RELEASE.md` as the body and
   `UncleCZNMMMI-v0.5.zip` as the asset (same flow as v0.4: `gh_release.py` in the Hermes
   scratch dir + curl upload; rename the asset afterwards since GitHub rewrites `'`).
6. If option B (R2) was chosen: upload `latest.json` + the zip; `UPDATER_URL` points there.

## Risks / tradeoffs / open questions

1. **Private repo = no unauthenticated read.** Resolved by the host decision above;
   never ship a token in the exe, never scrape with credentials.
2. **The check is the tool's first network call.** One plain GET, no query data, no
   identifiers; documented in the README. If you want a toggle, add
   `QSettings("CZN_MMMI","tool")` key `upd_auto` on the same Settings row - deferred
   until someone asks (YAGNI).
3. **Unsigned exe + auto-update** = unchanged SmartScreen story (each new exe still
   warns once); code signing is a separate decision (see chat notes).
4. **GitHub rate limit** 60 req/h/IP unauthenticated - plenty for a manual button +
   one startup check; still, respect it: never retry in a loop.
5. **Version format**: compare tolerates `0.4.1` and `0.5`; tag `v`-prefix is stripped.
6. **QA must never hit the network** - the module reads a module-level `fetch`, and the
   auto-check is gated to frozen runs; both are load-bearing for offline CI.

## Phase 2 (NOT this plan; revisit only if support load demands it)

Full self-update: download the zip to `update.tmp`, verify `sha256` from the metadata,
spawn a shim (small `.bat` or `--apply-update` second instance) that waits for the app to
exit, replaces the exe, relaunches. ~100 lines + the deadlock/paths/integrity tests -
opt-in, off by default, and clearly labelled "auto-update" in Settings.
